Spring Boot 웹 개발 실습

강의 순서대로 정리한 패키지별 예제입니다.

00 스프링 기반과 DI web00

  • 계층(컨트롤러→서비스→리포지토리) · 등록된 빈 목록 · @Primary·@Qualifier

01 요청과 응답 web01

  • 요청 매핑 · @RequestParam · @ModelAttribute(JSON)
  • 응답: 뷰 템플릿 · JSON · Forward/Redirect (PRG)
  • 파라미터 바인딩 심화: 폼(select·radio·checkbox → 배열) · MultiValueMap
  • Forward/Redirect 비교: forward · redirect · ResponseEntity

02 Thymeleaf web02

  • 타임리프 실습 목록 (출력·반복·조건·조각·레이아웃)

03 쿠키·세션 / 검증 web03

  • 쿠키·세션 상태 화면 · 세션 정보
  • Bean Validation 폼 (검증 그룹 비교는 curl: POST /ex03/groups/save|update|valid)

04 JPA 기초 web04

  • 영속성 컨텍스트·1차 캐시·변경 감지 데모 → 앱 시작 시 콘솔에 자동 출력 (SQL 로그와 함께)

05 Spring Data JPA web05

  • 쿼리 메소드·페이징·N+1·DTO 데모 → 앱 시작 시 콘솔에 자동 출력
  • 회원 목록(DTO) · 페이징 API
  • 페이징 목록 화면(페이지 블록) · 복합 조건 검색
  • H2 콘솔 (JDBC URL: jdbc:h2:mem:testdb)

06 필터·인터셉터·예외 처리 web06

  • 공개 · 인터셉터 보호 · 필터 보호 · 로그인
  • 오류 페이지: 500 · 404 · 400
  • @ExceptionHandler: 컨트롤러 안 (409) · @ControllerAdvice (501)
  • API 예외: 정상 · 400 · 500

07 파일·페이징 web07

  • 파일 업로드/다운로드
  • 페이징 계산(LIMIT/OFFSET)

08 REST API web08

  • API: GET 목록(JSON) · GET 단건 · 없는 할 일 (404 JSON)
  • 화면 비교: 서버에서 그린 화면(SSR) · fetch로 그린 화면

09 테스트 test01 test02 test03

  • 화면이 없다. 터미널에서 ./gradlew test (JUnit 기초: --tests "com.example.basic.test01junit.*", 단위/통합: --tests "com.example.basic.test02unitintegration.*", 테스트 설계와 TDD: --tests "com.example.basic.test03tdd.*")

10 Spring Security web10

  • 실습 홈 · 로그인 · 내 정보(로그인 필요)
